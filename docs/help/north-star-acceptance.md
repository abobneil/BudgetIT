# Help Center North-Star Acceptance Tests

Run these scenarios after major Help Center changes.

## Scenario A: Brand-New User

1. Understand what BudgetIT is for from Help Center content.
2. Complete baseline setup (vendors, services, contracts, expenses, dimensions).
3. Import actuals and reconcile unmatched rows.
4. Interpret dashboard KPIs and variance.
5. Produce an executive export.
6. Follow weekly and monthly operating guidance.

Pass criteria: all six tasks are completed in-app without external docs.

## Scenario B: Experienced User

1. Press `F1` from a non-help route.
2. Search or jump to the relevant topic/anchor.
3. Find a definition, status meaning, or field meaning in under 30 seconds.

Pass criteria: all three tasks complete successfully within SLA.
